# Ed25519 vectors

`zip215.json` is the 196-case ZIP-215 compliance corpus published with
`@noble/curves` 2.2.0. The cases originate from Henry de Valence's ZIP-215 test
vectors and verify the fixed UTF-8 message `Zcash`. The vendored copy adds one
terminal line feed to the upstream JSON.

- Source: https://github.com/paulmillr/noble-curves/blob/2.2.0/test/vectors/ed25519/zip215.json
- ZIP: https://zips.z.cash/zip-0215
